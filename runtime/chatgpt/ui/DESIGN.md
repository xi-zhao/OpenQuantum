# OpenQuantum 共享设置页

本页帮助科研用户发现能力、了解如何提问、理解账户要求并完成本机运行环境配置。Codex 应用与 Desktop「设置 → OpenQuantum」共用 `app.html`、`app.mjs`、`style.css` 和 `identity.css`；宿主拥有聊天、模型以及各自的配置和凭据。

## 视觉约定（Brand System 2.0）

设置页是面向科研人员的桌面操作工作台。沿用 OpenQuantum 标志、浅色建筑纸白 / 深色深邃黑曜石画布、量子青主强调色与系统字体；品牌体现在清晰的表面层次、紧凑可读的目录密度和准确的状态表达。

| 角色 | 浅色值 | 深色值 | 用途 |
| --- | --- | --- | --- |
| 画布 | `#ffffff` | `#0b1118` | 详情工作区与页面底色 |
| 目录栏 | `#f8fafc` | `#0d141d` | 左侧目录与筛选工具栏 |
| 卡片表面 | `#ffffff` | `#121c28` | 指标卡、环境卡与详情头部 |
| 主强调色 | `#0e7490` | `#38bdf8` | 当前选中、领域计数与焦点提示 |
| 主操作 | `#0a2438` | `#38bdf8` | 主要按钮与已启用开关 |

完整的深浅色、焦点、成功、警告与错误变量以 `identity.css` 为准。不请求远程字体或外部资源。

## 布局与交互

两宿主使用完整可用工作区，不按宿主固定窄栏。宽窗左侧 332px 目录栏，右侧为详情区；列表与详情独立滚动，默认选中按分类展示顺序的第一条可见项目。视口不超过 720px 时切换为列表或详情单栏，返回时保留搜索、筛选和列表位置。

首页完全基于实时 `snapshot` 渲染，不包含固定服务示例或假待办：
- 平台理念与 Skills / MCP 主入口；
- 实时规模与就绪概览（Skills、MCP 服务、本机运行环境、云端服务账户）；
- 仅在存在真实待处理 Skill 或进行中的安装任务时出现的提醒条；
- 按 `snapshot.categories` 动态生成的 8 个研究方向直达卡片，点击即可带筛选跳转至对应 Skills；
- 面向初次使用者的三步工作说明。

目录支持名称/领域/用途搜索、快速筛选芯片与用途/状态下拉筛选；详情页在账户与环境卡片之上提供可一键复制的「试试在对话里这样问 Agent」示例提问卡片，降低上手门槛。

键盘支持 Tab、方向键（主导航与目录条目；窄屏 `≤720px` 上下键仅移动焦点，回车打开详情）、Home/End、全局 `/` 快速聚焦搜索（在窄屏详情页按 `/` 会先回到列表并聚焦搜索框），快捷筛选芯片切换后恢复焦点；搜索框支持中文输入法与 Escape 清空。状态同时使用文字与颜色，支持深色主题、可见焦点、减少动画和强制颜色偏好。

## 保存边界与进度读取

未提交的账户输入仅留在当前页面内存，切换条目或认证方式不写设置；页面关闭时清除。逐字段保存沿用加密提交、一次性 nonce 和保存后回读，已保存秘密不回显；未知写入结果不自动重试。账户已保存不表示认证通过，许可已开启不表示远端在线。

所有入口取得的新快照统一交给 `PreparationPoller`；仅在有 `preparing`/`cancelling` 环境时安排下一次读取，编辑输入、写入或隐藏页面时自动延后/暂停，完成后按原 `jobId` 报告结果。
