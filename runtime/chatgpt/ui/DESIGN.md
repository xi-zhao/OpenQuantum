# OpenQuantum 共享设置页

本页帮助科研用户找到能力、理解账户要求并完成配置。Codex 应用与 Desktop「设置 → OpenQuantum」共用 `app.html`、`app.mjs`、`style.css` 和 `identity.css`；宿主拥有聊天、模型以及各自的配置和凭据。

## 视觉约定

设置页是电脑上的操作界面。沿用 OpenQuantum 标志、白色画布、深蓝操作色与系统字体；品牌体现在清晰的层级和准确的状态表达。

| 角色 | 浅色值 | 用途 |
| --- | --- | --- |
| 画布 | `#ffffff` | 页面与目录条目 |
| 次级表面 | `#f5f5f7` | 提示及空状态 |
| 正文 | `#1d1d1f` | 标题和主要文字 |
| 辅助文字 | `#63636a` | 用途、范围与准备说明 |
| 主操作 | `#0a2438` | 主要按钮、已启用开关 |
| 选择背景 | `#edf4f7` | 当前导航与目录条目 |

完整的深浅色、焦点、成功、错误与待处理颜色以 `identity.css` 的语义变量为准。不请求远程字体。正文 15px，辅助文字 13px，目录标题 14px，详情标题 22px，页面标题 24px，首页理念标题 28px。长文本自然换行，首页正文限制为 46em。

## 布局与交互

两宿主使用完整可用工作区，不按宿主固定窄栏。Desktop 通过现有品牌设置 Modal 扩展窗口，共享页面内部不感知宿主窗口实现。宽窗左侧 304px 目录，右侧为详情；列表与详情独立滚动。视口不超过 720px 时切换为列表或详情单栏，返回时保留搜索、筛选和列表位置。

首页仅保留 README 中「共建可信的量子科研智能。」、第一段平台介绍及 Skills/MCP 入口。没有固定服务示例、假待办或最近记录区块。

目录提供名称/用途搜索、常显用途和状态筛选、准确的数量。Skills 不把无关联的内置 Tool 计入 Skill 数；内置 Tool 单独分组，仍可管理许可。账户提示独立于许可开关。选中条目后才构建它的表单。

详情先显示账户，再显示环境和工具限制。IBM 共用字段在同一宿主内复用；FieldQKit 按所选平台显示；QCArchive 保留地址与可选用户名/密码；Pasqal 在对应 Skill 下选择 Token 或密码认证。自建 MCP 仍通过独立本机凭据窗口配置 Token，操作绑定连接实例。

导航支持 Tab、方向键和 Home/End；搜索支持中文输入法，Escape 清空查询并保留其他筛选。状态同时使用文字与颜色，支持深色主题、可见焦点、减少动画和强制颜色偏好。

## 保存边界

未提交的账户输入仅留在当前页面内存，切换条目或认证方式不写设置；页面关闭时清除。逐字段保存沿用加密提交、一次性 nonce 和保存后回读，已保存秘密不回显。未知写入结果不自动重试。账户已保存不表示认证通过，许可已开启不表示远端在线。环境准备与真实调用仍受现有宿主规则约束。
