OpenQuantum Harness-first 架构

OpenQuantum 是 DeepSeek Harness 的量子科研发行版，而不是第二套 Agent Runtime。所有用户意图、工具调用、模型推理、权限审批和持久化都经过 Harness；量子能力由相互独立的 Skill、MCP/Tool 与 Validator/eval 组合。

一个运行时，一个执行事实源

Session、Turn、Step、Goal、Job、权限、审批、沙箱、工具调度与恢复全部属于 Harness。OpenQuantum 不建立平行状态机，Session Event Log 是执行事实的唯一来源。

运行状态与科学状态正交

工具成功或 Harness idle 只说明执行结束；科学验收必须由版本化 Validator + Profile 根据真实产物独立派生。
