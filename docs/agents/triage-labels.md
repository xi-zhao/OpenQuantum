# Triage Labels

工程技能使用以下五个角色；对 GitHub Issues 应用标签时使用右侧映射。本仓库保留默认标签名。

| Label in mattpocock/skills | Label in our tracker | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待维护者分类与判断 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 需求与验收条件明确，可由 Agent 实施 |
| `ready-for-human` | `ready-for-human` | 需要人工实施 |
| `wontfix` | `wontfix` | 决定不处理 |

标签表达工单状态，不授予额外执行权限。后续如需改名，更新映射并核对 GitHub 上的实际标签，避免创建含义重复的标签。
