# 设置页交互原型

日期：2026-10-29。目标：电脑端的 OpenQuantum 设置窗口与 Codex 侧边应用。交互稿：[打开原型](settings-prototype.html)。原型用于评审交互，尚未替换正式设置页。

## 方向

保留 OpenQuantum 标志、系统字体、白色画布、深蓝操作色，以及「首页 / Skills / MCP」导航。电脑设置窗口采用可搜索列表与右侧详情；Codex 窄侧栏在列表与详情之间切换，返回后保留筛选和位置。

首页介绍 OpenQuantum 理念，采用根目录 [README 首屏](../../README.md) 的「共建可信的量子科研智能」、副标题及两段原文，说明开放共建、专业软件与研究成果的连接，以及研究记录的复用。电脑宽窗口限制正文行宽，Codex 侧栏自然换行；Skills、MCP 目录入口放在介绍之后。原型默认打开首页，不放固定服务示例、不虚构最近使用或待办。账户配置从对应 MCP 或 Skill 的详情进入。

MCP 列表直接说明账户要求，并将需要处理的字段作为入口。详情首先显示账户表单，其次是运行环境与工具说明。允许使用的开关独立于账户和环境状态。切换服务不会把未保存的输入写入设置，也不会丢弃本页草稿。

原型的关键动作是从「云端待填 Token」直接到对应字段。IBM Runtime、Transpiler 和硬件连接使用当前宿主的同一份 IBM Token；FieldQKit 先选平台；QCArchive 区分公开服务器与用户名/密码配对；Pasqal 云端账户属于 Skill，不伪装成一个 MCP。自建 MCP 的 Token 在独立凭据窗口填写，列表与详情均提供明确入口。

## 状态和安全边界

- 许可、环境、凭据三个状态分别表达，不用一个「已连接」概括。
- 逐字段保存；空输入不能保存，已有秘密不回显，删除需要确认。
- 保存成功只表示凭据已保存，不表示平台认证已验证；不自动发出量子任务。
- Codex 与 Desktop 的账户、环境、许可状态按宿主隔离；共享字段仅在同一个宿主内复用。
- 原型使用本页内存和演示值，不接真实凭据库、不安装环境、不连接云端；刷新可重置。正式实施继续复用现有 Application Interface、加密提交和回读核对，不新增秘密存储。
- 原型中的目录是真实源码快照；许可、环境和已保存标记是明确标注的演示状态。

## 验收范围

浏览器检查应覆盖：两种电脑容器、搜索与筛选、列表和详情返回、演示凭据的保存/替换/移除、IBM 共用字段、宿主隔离、FieldQKit 平台切换、QCArchive 字段配对、Pasqal 认证方式、无凭据服务、自建 MCP 凭据窗口，以及键盘焦点和无横向溢出。这里只验证原型交互，不替代正式应用的集成与安全测试。

实际浏览器验证：15 组交互检查通过（包含自建免认证连接与统一筛选的回归），无 JavaScript 错误，无外部请求。两种容器在 360–1440px 视口下均无横向溢出；正文、辅助文字与账户提示对比度分别为 15.69、5.68、5.81。检查使用演示值，未读取或改写真实账户。
