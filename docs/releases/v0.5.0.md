# OpenQuantum v0.5.0

OpenQuantum 的 Web 和 Desktop 现在使用同一个正式版本更新通道。新版本发布后，工作台会提示查看变更和升级步骤，让持续更新成为日常使用的一部分。

## 新增体验

- **版本更新设置**：查看 OpenQuantum 版本、检查时间和发布说明，也可从侧边栏进入。
- **自动与手动检查**：启动一分钟后检查，之后每天最多自动检查一次；Desktop 标题栏的检查命令复用同一服务。
- **可控的提醒**：支持明天再提醒、跳过当前版本和关闭自动检查；Web 与 Desktop 共享偏好。
- **十语言支持**：沿用工作台语言设置，覆盖中文、英语、日语、韩语、西班牙语、法语、德语、葡萄牙语、俄语和阿拉伯语。
- **正式发布通道**：仅在质量、macOS/Windows 桌面源码安装和容器检查通过后，发布对应版本的更新清单。普通 main 推送不触发用户升级提醒。

## 安装与升级

这是源码发行版，包含更新提醒、发布说明和升级指南；尚不包含原生安装包或自动下载安装。

已有用户需先按[源码升级步骤](../UPDATES.md#upgrading)安装本版，之后才能收到后续正式版本的提醒。较早版本没有这个检查入口，无法收到此次首发提醒。

- 使用 Node.js 24 或更新版本，从干净工作目录检出 `v0.5.0`，运行 `npm ci`。
- Desktop 用户还需运行 `npm run desktop:setup` 和 `npm run desktop:verify-install`。
- 升级前结束正在运行的任务，备份并保留配置、凭据和学习数据；详细步骤见[部署说明](../DEPLOYMENT.md)。
- 启动后在 **设置 → 版本更新** 核对版本，并手动检查更新。

本版保持 Harness `0.1.5-rc.1`、Desktop `2.0.7` 及现有量子计算依赖锁定版本。没有新增配置或科研数据迁移。

## 验证范围

更新协议、失败路径、偏好持久化、多语言界面、真实 Host/ACP 和桌面组合已通过本地专项验证；发布工作流还会执行完整质量检查、双平台桌面源码安装及容器启动验证。发布清单由这些检查全部通过后生成。

这些是软件与分发检查，不代表新的外部模型、真实量子硬件或科研结果验收。更新服务不调用模型、不提交计算任务，也不发送会话或课程内容。

版本清单协议、维护入口和后续安装包扩展约定见[版本更新维护说明](../UPDATES.md#publishing-a-stable-update)。
