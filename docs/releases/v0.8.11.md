# OpenQuantum 0.8.11：可靠关闭、准备进度与新增科研能力

本次更新让 Desktop 与 Codex 共用同一份有界 Tool 执行实现，修复关闭和准备进度的边界情况，并收录 0.8.10 之后进入主线的三项科研能力。

## 本次更新

- 关闭计算服务时先停止接收新调用，再等待所有在途资源清理；一处连接回收失败也不会跳过其他清理。重复关闭共享同一个结果，清理错误继续保护凭据。
- 设置页通过 Agent 或宿主通知读到新的环境准备状态后，持续更新进度；同页只保留一个轮询读取，隐藏暂停、返回恢复，任务结束后停止。
- Desktop 与 Codex 共用 Tool 参数校验、并发限制、权限复查和关闭协议。Desktop 的原生计算仍在进程内，Codex 仍使用其 MCP 适配；各宿主继续拥有会话、模型和执行循环。
- 新增 [SlowQuant 分子响应](../integrations/SLOWQUANT.md)、[TNQS 平面张量网络](../integrations/TNQS.md)与 [RcmpsCore 连续场论](../integrations/RCMPS.md)的原生 SDK 工作流、固定环境及独立数值参考。各能力的已验证范围和限制见对应文档，不将工程测试视为所有研究任务的科学验收。
- 整理 [44 组状态协议的归属、迁移和恢复规则](../architecture/STATE_LIFECYCLES.md)，为后续能力和宿主维护提供可追踪入口。

## 下载与兼容性

- [Desktop v0.8.11](https://github.com/xi-zhao/OpenQuantum/releases/tag/v0.8.11)：Mac Apple Silicon 独立 DMG 与 `SHA256SUMS`。
- [Codex codex-v0.8.11](https://github.com/xi-zhao/OpenQuantum/releases/tag/codex-v0.8.11)：完整安装包、独立插件 ZIP 与 `SHA256SUMS`。

两端使用同一产品版本和源码提交。Tool 名称与输入合同、设置数据格式及宿主边界保持兼容。Desktop 继续固定 DSH Desktop `2.0.0`、Harness `0.1.0-rc.6` 与 V0 会话格式；没有迁移为更新的上游会话格式。

按 [Desktop 安装说明](../DESKTOP_INSTALLERS.md)或 [Codex 安装说明](../integrations/CODEX_AGENT_INSTALL.md)核对摘要、备份并升级，保留会话、设置、凭据与已有计算环境。Mac 包采用 ad-hoc 签名，未做 Apple Developer ID 分发签名或公证；Intel Mac 与 Windows 的既有能力包渠道保持原样。

## 验证范围

发布前已在合并源码上完成 218 项相关回归，4 项需要真实环境开关的用例条件跳过。该结果不是最终安装包验收。最终源码提交、CI、包摘要、启动和宿主验证，以各 Release 的 `release-verification.json` 或 `release-validation.json` 为准。

本次发布不会自动替换用户本机安装，不请求真实外部模型、量子云或硬件；这些运行结果不由发行检查推定。
