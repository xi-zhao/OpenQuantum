## 必要适配

- Preset：官方 `dsh-agent-preset` 显式声明替代目录扫描。声明文件写到 `profiles/.agent-presets/presets.cordis.yml`，
  从当前 Host 的同一依赖图解析；每个 preset 目录链接项目依赖。
- 模型：route catalog 与默认模型/默认 preset 作为 profile bundle（Web/ACP 为 `@openquantum/harness-model-routes`，
  Desktop 复用 `@openquantum/harness-desktop-profile`）装入，低于各 profile 原生 `cordis.patch.yml`，
  因此设置中的修改重启不回滚。复用上游顶层 `llm-pi-ai` 行。
- 旧 `settings.yaml`：`llm-pi-ai`、`agent-default-model`、`agent-presets.default` 一次性迁入 Web+ACP（或 Desktop）
  profile，已有 profile 选择优先；完整原文先备份为 `settings.yaml.openquantum-v021-backup`，其余设置交给官方导入。
- 行为变化：迁移后各 profile 独立保存模型覆盖，Web 中的修改不再自动进入 CC Connect ACP。
- 关闭上游新增的账号模型入口、会话日志上传与产品遥测默认项。
- Persona 去掉 `{{cwd}}`：0.2.1 不再注册该变量（未注册变量会让提示组装失败），工作目录由官方 working-directory 服务提供。
- Session V4：Tool 结果改为 `role: "tool"` 消息；兼容检查允许到 V4，拒绝 V5 及以上。
- Runtime readiness 改读 `agentPresets.generations`；ACP 首次握手等待 Agent 扩展子树就绪。
