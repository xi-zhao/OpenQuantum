# OpenQuantum 0.8.8：白底应用图标

OpenQuantum 的应用图标改为白色圆角底板，保留原有轨道标志与配色。
Dock 运行时图标、独立 Mac 安装包和品牌启动器使用同一组桌面图标，避免启动后恢复为透明底。
Web 和菜单栏仍使用适合各自背景的透明标志。

## 安装与兼容性

从 [v0.8.8 Release](https://github.com/xi-zhao/OpenQuantum/releases/tag/v0.8.8) 下载
`OpenQuantum-0.8.8-macOS-arm64.dmg` 和 `SHA256SUMS`。核对摘要，退出旧版并备份数据后，
把镜像内的 `OpenQuantum.app` 拖入「应用程序」。本次独立安装包只覆盖 macOS Apple Silicon。

继续使用 `~/Library/Application Support/OpenQuantum/Desktop/`，保留已有会话、模型与设置。
更早的 V3 会话及阅读副本保持独立，不转换为旧格式。
基线仍为 DSH Desktop **2.0.0** / Harness **0.1.0-rc.6**；Codex 公开插件仍为 `codex-v0.8.4`。
**应用为 ad-hoc 本地签名，尚未取得 Apple Developer ID 分发签名或公证。**
完整安装方式见[安装说明](../DESKTOP_INSTALLERS.md)。

## 实现与验证范围

- 图标从现有矢量标志生成，复用固定桌面构建已有的绘图库；没有新增生产依赖。
  共享 Skills、Tool implementation、MCP Server、模型路由与会话格式未改。
- 完整本地工程检查与 17 项品牌定向检查通过。初始干净构建已在本机安装，
  应用信息窗口显示白底图标与 0.8.8，已有验收会话和 Magpie 选择恢复，12 个受保护文件摘要不变。
- 最终源码、PR/main 检查、DMG 摘要、签名与启动证据以 Release 附件
  `release-verification.json` 为准；附件只包含验证摘要，不包含个人会话或凭据。
- 当前 GUI 工具未直接捕获 Dock 和右上角菜单栏弹出层。图标资源、原生菜单策略及回调检查
  与可见操作验收分开记录；本次未发送新的模型请求。
