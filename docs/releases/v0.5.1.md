# OpenQuantum v0.5.1 — 桌面安装包 / Desktop installers

OpenQuantum 是开源量子 Agent 平台。v0.5.1 把工作台和所需的 Node.js、uv / uvx 一起交付，让用户可以下载安装后直接打开工作台，无需先配置源码构建环境。

## 下载与安装

本次正式 Release 附带**未签名的测试安装包**；尚未完成 Apple 签名、公证或 Windows 签名，首次打开可能出现系统安全提示。

| 系统 | 下载 | 安装方式 |
| --- | --- | --- |
| Mac，Apple Silicon | [macOS ARM64 DMG](https://github.com/xi-zhao/OpenQuantum/releases/download/v0.5.1/OpenQuantum-0.5.1-macOS-arm64.dmg) | 打开 DMG，将 OpenQuantum Desktop 拖入 Applications 后启动 |
| Mac，Intel | [macOS x64 DMG](https://github.com/xi-zhao/OpenQuantum/releases/download/v0.5.1/OpenQuantum-0.5.1-macOS-x64.dmg) | 同上 |
| Windows，64 位 | [Windows x64 安装程序](https://github.com/xi-zhao/OpenQuantum/releases/download/v0.5.1/OpenQuantum-0.5.1-Windows-x64-Setup.exe) | 运行安装向导，再从开始菜单启动 |

[SHA256SUMS 校验文件](https://github.com/xi-zhao/OpenQuantum/releases/download/v0.5.1/SHA256SUMS)覆盖以上三个文件。安装器、应用内版本和此标签均为 `0.5.1`。

首次进入工作台后，在设置中配置自己的模型服务。部分 Python 计算组件首次使用时需要联网准备固定依赖；Julia、Git 相关可选组件和量子学习通仍有各自的安装步骤。

## 本版变化

- **安装后即可打开工作台**：内置固定版本的 Desktop / Harness、Node.js 24.14.1 和 uv / uvx 0.11.1，打开应用无需先安装 Node、npm 或编译器。
- **统一 OpenQuantum 品牌**：首次设置、恢复界面、原生图标与安装程序使用 OpenQuantum 标识。
- **为持续升级保留数据**：程序与可写用户数据分离；更新内置程序时保留会话目录、自定义配置和 Skill，用户改过的默认内容不会被静默覆盖。
- **修复安装版启动**：等待部署准备完成后再启动 Desktop，并补齐 Windows 启动诊断。目录调试构建独立输出，保留已有安装包。

## 升级与验证范围

升级前结束任务、退出应用并备份用户数据。已有安装版可下载并覆盖安装；源码版使用干净的 `v0.5.1` checkout，运行 `npm ci`，Desktop 用户另运行 `npm run desktop:setup` 和 `npm run desktop:verify-install`。安装版使用独立数据目录，不自动搬移源码版或原 DSH Desktop 的数据。

v0.5.0 及更新版本可通过 **设置 → 版本更新** 检查新版本，提醒后打开本发布页下载。当前不支持后台自动下载安装或自动重启。

每个平台的附件均须通过原生安装检查：Mac 从 DMG 复制安装，Windows 执行静默安装，随后检查两次真实 Host / renderer 启动、内置运行环境、自定义配置与 Skill 保留和固定本地量子工具。自动测试使用已跳过首次设置的测试状态；人工首次向导检查覆盖 Apple Silicon，未覆盖 Intel Mac 和 Windows 的安装向导交互。

本版继续固定 Harness `0.1.5-rc.1`、Desktop `2.0.7` 和既有量子计算依赖，不新增外部模型、真实量子硬件或科研结果验收结论。

## English

OpenQuantum is an open-source quantum Agent platform. v0.5.1 adds native desktop installers for Apple Silicon Macs, Intel Macs and Windows x64. The application bundles the pinned Desktop / Harness, Node.js and uv / uvx, so opening the workbench does not require a separate source build or Node installation.

**The installers are unsigned test builds**, attached to this regular GitHub Release. Apple signing, notarization and Windows signing are not yet configured. Configure your own model service after installation; optional scientific and learning components retain their documented setup requirements.

Downloads and SHA-256 checksums are linked above. Each installer must pass native installation, two actual Host / renderer launches, bundled-runtime checks, custom configuration and Skill retention, and a fixed local Tool check. Manual first-run UI coverage is limited to Apple Silicon. These checks do not establish external-model, QPU or new scientific acceptance.

Back up your data and quit the app before replacing an existing installation. Source users should use a clean `v0.5.1` checkout and follow the versioned upgrade guide. Installer data is separate from source installations and is not migrated automatically. Existing v0.5.0 users can discover this version through Settings → Updates; updates remain user-installed.
