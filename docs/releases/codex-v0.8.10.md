# OpenQuantum Codex 插件 0.8.10

此版本与 [Desktop 0.8.10](v0.8.10.md) 来自同一源码提交，修复共享设置页内容区过小与滚动不完整的问题。品牌和导航合并为一行，目录页收拢重复标题和页尾；筛选区与列表一起滚动，详情支持键盘翻页，短窗口底部可以完整查看。

从 [codex-v0.8.10 Release](https://github.com/xi-zhao/OpenQuantum/releases/tag/codex-v0.8.10) 下载 `openquantum-0.8.10-codex-install.zip` 与 `SHA256SUMS`，按 [安装指南](../integrations/CODEX_AGENT_INSTALL.md) 核对、安装并重载插件。保留 `openquantum@personal` 身份、已有设置、凭据与计算环境。

插件继续使用 Codex 原生对话、模型与执行循环；科学 SDK 仍按任务准备。最终完整安装包、原生宿主注册和本机界面验证以 Release 的 `release-validation.json` 为准。
