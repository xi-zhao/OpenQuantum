# OpenQuantum 0.8.4 — 原生 SDK 生态扩展

OpenQuantum 0.8.4 增加 **26 个原生 SDK/源码入口**，覆盖纠错与编译、噪声表征、光子学、量子机器学习、原子模型、控制与网络模拟。完整清单、固定版本、许可和实际检查范围见[生态扩展记录](../integrations/SDK_ECOSYSTEM_2026-10-14.md)。本轮不纳入旧运行栈的 QuCumber。

SDK/源码环境目录增至 **111 项**，Desktop 源 Skill 增至 **183 项**；环境按需显式准备。Agent 使用宿主代码工具编写、修改和执行原生程序，本轮不增加科学 Tool 或 MCP 连接。原有 TensorCircuit 入口迁移到 `tensorcircuit-ng==1.10.0`，Skill ID 与 Tool 名称保持稳定；MQT Bench v2 固定 2.3.0，增加 21 个参数与相位可追溯的语料，保留 v1。

本版同时包含已合并的量子组件设置改动，统一运行状态、MCP、Skills、服务密钥四个标签。模型、SDK 环境及厂商账户仍按用户需求配置，发行不会自动提交云任务。

## 下载与安装

| 系统 | OpenQuantum 能力包 |
| --- | --- |
| Mac Apple Silicon | `OpenQuantum-0.8.4-DSH-darwin-arm64.tar.gz` |
| Mac Intel | `OpenQuantum-0.8.4-DSH-darwin-x64.tar.gz` |
| Windows x64 | `OpenQuantum-0.8.4-DSH-win32-x64.tar.gz` |

先安装 [anywhere-labs 原版 DSH Desktop 2.0.7](https://github.com/anywhere-labs/dsh-desktop/releases/tag/v2.0.7)，再下载对应能力包。按同页 `SHA256SUMS` 核对摘要，退出正在运行的 OpenQuantum Host，备份数据目录并解压；Mac 运行 `install.command`，Windows 运行 `install.cmd`。完整步骤见[安装与迁移说明](../DESKTOP_INSTALLERS.md)。

OpenQuantum 产品版本为 **0.8.4**，原版客户端为 **2.0.7**，Harness 为 **0.1.5-rc.1**。能力包包含 Node、uv 和锁定程序依赖；科学 SDK、Julia 与 C++ 构建环境按条目显式准备。TensorCircuit 升级前保留已有环境与结果；Julia 固定 1.12.7，Qsyn 本轮在 GCC 16.2.0 下验证构建，其他编译器须独立验证。发布不替换用户已有安装，不改写 Harness 0.2 的 V4 Home。

## 验证范围

26/26 个新增 SDK 的实际 API 示例已在 macOS arm64 的禁止网络进程中检查；TensorCircuit 迁移与非零梯度对照、完整酉矩阵语料检查、全仓工程检查及独立审查通过。版本、原始程序、输出和摘要见[持久工程证据](../integrations/evidence/sdk-ecosystem-2026-10-14.json)。这些检查不穷尽上游 API，不覆盖其他系统的科学 SDK、GPU、真实硬件或完整科研任务。

正式附件要求当前发布提交的 7 项 CI 全部通过，包括三平台能力包安装、再次安装、配置保留与捆绑环境检查。最终提交、检查和附件摘要以 Release 的 `release-validation.json` 为准。原生界面及视觉检查沿用各功能已记录的验收范围；跨平台安装检查不代替原生界面验收。

未进行真实科研任务、外部模型或 Cloud/QPU 验收，`scientificValidation=not_evaluated`。
