# OpenQuantum 0.8.3 — 设置分类与 Desktop 品牌图标

Desktop 能力包与 [Codex 插件 0.8.3](https://github.com/xi-zhao/OpenQuantum/releases/tag/codex-v0.8.3) 使用同一产品版本和源码提交。本版降低设置页的信息密度，并补齐 OpenQuantum 的桌面启动图标。

## 本版变化

- Tools、MCP、Skills 按 8 个用途分组，默认折叠并显示数量；支持按名称或用途搜索，以及用途、启用状态筛选。未知条目和自定义连接保留在“其他与自定义”，连接详情按需展开。
- Mac 安装器提供带 OpenQuantum 图标的 `OpenQuantum.app`，默认安装同时在 `~/Applications` 创建入口；Windows 提供带品牌图标的 `OpenQuantum.lnk`。运行图标通过原版 Desktop 的公开接口传入。
- 更新时检查启动文件的归属，保留用户修改与已有配置。原版客户端的界面、名称、版本、签名资源和更新渠道保持原样。

品牌、量子组件、量子学习通与 OpenQuantum 更新入口继续保留。模型仍由用户自行添加，分类不会改变组件的启停、凭据或执行行为。

## 下载与安装

| 系统 | OpenQuantum 能力包 |
| --- | --- |
| Mac Apple Silicon | `OpenQuantum-0.8.3-DSH-darwin-arm64.tar.gz` |
| Mac Intel | `OpenQuantum-0.8.3-DSH-darwin-x64.tar.gz` |
| Windows x64 | `OpenQuantum-0.8.3-DSH-win32-x64.tar.gz` |

先安装 [anywhere-labs 原版 DSH Desktop 2.0.7](https://github.com/anywhere-labs/dsh-desktop/releases/tag/v2.0.7)，再下载对应能力包。按同页 `SHA256SUMS` 核对摘要，退出正在运行的 OpenQuantum Host，备份已有数据目录并解压；Mac 运行 `install.command`，Windows 运行 `install.cmd`，随后使用安装器输出的 OpenQuantum 入口。不要删除 `versions/`。

能力包包含 Node、uv 和锁定程序依赖，不包含修改版的 DSH DMG/EXE。OpenQuantum 产品版本为 **0.8.3**，原版客户端为 **2.0.7**，Harness 保持 **0.1.5-rc.1**。不支持用此版本改写 Harness 0.2 的 V4 Home。设置过原生数据目录的用户，须在 DSH Desktop 中选择本次安装的 `project/.openquantum/dsh`。

详细步骤见[安装与迁移说明](https://github.com/xi-zhao/OpenQuantum/blob/v0.8.3/docs/DESKTOP_INSTALLERS.md)。发布本身不会替换用户已有安装。
