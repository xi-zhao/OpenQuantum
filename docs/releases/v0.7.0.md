# OpenQuantum v0.7.0

本版将现有量子库扩展为可编写原生程序的 SDK 工作环境。**85 个 SDK/源码环境入口**提供完整包或源码、固定依赖、显式安装步骤和公开 API 导航。用户可以组合自己的模型、算法、参数、输入和控制流程；已有便捷 Tool 继续提供常用动作，其预设案例不再定义库的功能上限。

这里的 85 项是环境入口，不是 85 个不同上游库。“完整接入”表示原生公开 API 可访问，不表示全部 API、可选后端、操作系统或云服务已经验证。定义、逐库范围与复跑入口见[完整 SDK 接入记录](../integrations/FULL_SDK_ACCESS.md)和[环境清单](../integrations/SDK_INVENTORY.md)。

## 下载与升级

从 [v0.7.0 Release](https://github.com/xi-zhao/OpenQuantum/releases/tag/v0.7.0) 下载适合平台的安装文件，并核对同一 Release 中的 `SHA256SUMS`：

- `OpenQuantum-0.7.0-macOS-arm64.dmg`：Apple Silicon Mac。
- `OpenQuantum-0.7.0-macOS-x64.dmg`：Intel Mac。
- `OpenQuantum-0.7.0-Windows-x64-Setup.exe`：Windows x64。

这些仍是**未签名测试构建**，没有 Apple 签名/公证或 Windows 代码签名。可用文件以 Release 实际附件为准。
使用新安装包覆盖应用；用户目录、会话、模型配置和已修改的 Skill/MCP 配置按[安装升级规则](../DESKTOP_INSTALLERS.md#数据与升级)保留。保留的自定义配置可能需要与新默认配置比较，才能采用新入口。

安装包携带适配代码和依赖定义，不会批量安装 85 个数值环境。按任务显式准备所需环境；账户、鉴权、服务权限、许可和特殊硬件由用户配置。SDK 的 macOS/Linux/Windows 支持及私有依赖限制见逐库清单。Harness `0.1.5-rc.1`、Desktop `2.0.7` 与内置 Node.js `24.14.1` 保持不变。

## 本版变化

- 原生 SDK workbench 和领域 Skill 使用宿主已有文件与代码工具运行自定义程序，不新增任意代码执行 MCP。首次准备依赖与后续计算分开，保留宿主权限、超时和取消机制。
- 补齐 Flow-VQE 完整源码、CQLib QML 完整包、Ocean 元包，以及 QPanda、Qcover、SpinQit、VQNet 的导入依赖与兼容处理；补充 QCEC 的 Qiskit extra、TensorCircuit 的优化/转换依赖，并修复 QAT 共享 console wrapper 的安装校验。
- 默认 Harness Preset 将大型科学结果完整保存为 JSON，再返回可读取的摘要和文件引用；小结果沿用既有合同。详情见[大结果交付](../integrations/SCIENCE_RESULT_DELIVERY.md)。
- 保留 Desktop 与 Codex 的独立产品入口。Codex 插件同步发布为 [0.8.0](codex-v0.8.0.md)，不会取代 Desktop 的稳定更新通道。

## 工程验证与证据

SDK 接入在 macOS arm64 上完成首批 13 项及后续 30/24/18 项原生 API 工程检查，合计 85 个环境。检查覆盖固定版本、公开模块、自定义对象、序列化或工件等各自适用路径；不是每库所有 API 的穷举测试。部分服务 SDK 仅运行本地程序和配置，未连接真实账户、QPU 或仪器。

[逐库记录](../integrations/FULL_SDK_ACCESS.md)链接三个不可改写的版本化报告及原始证据归档。归档可在没有原工作区和 SDK 的新目录中离线校验。失败尝试中未保留的两个中间依赖快照已明确列为证据缺口；最终成功记录不受影响。

发布以对应提交的 CI、Mac arm64/x64 与 Windows x64 安装检查、附件摘要和稳定更新清单核对为条件。CI 安装检查验证应用启动、版本和数据保留，不代表这些平台的全部 SDK 已运行。逐包结果以 Release 的 `release-validation.json` 和关联工作流为准。

**按用户要求，本版没有使用真实科研任务做验收。** 既有科学合同和阈值不变；`scientificValidation=not_evaluated`。工程检查、工具执行和安装成功均不等于科学 Acceptance。没有做真实云提交、QPU、实验室设备或外部模型验收。

## English

OpenQuantum v0.7.0 exposes native SDK workflows for 85 pinned SDK/source environments. Users can write custom programs and compose public APIs beyond the existing convenience tools. The release also preserves full scientific-result files in the Harness workflow and adds portable engineering evidence. Installers remain unsigned test builds; SDK dependencies require explicit, per-task setup. Engineering checks do not establish exhaustive API coverage, cross-platform SDK support or scientific acceptance. See the release assets and validation record for the exact shipped artifacts.
