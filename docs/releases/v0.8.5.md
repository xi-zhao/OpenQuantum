# OpenQuantum 0.8.5：简洁个人桌面

此版本提供 **macOS Apple Silicon 独立安装包**。将 `OpenQuantum.app` 放入「应用程序」即可启动，
桌面程序、Node、uv 与锁定依赖均包含在应用中。Codex 插件的公开版本仍为 `codex-v0.8.4`；
Intel Mac 和 Windows 暂沿用此前的能力包，本次不宣称完成这些平台的独立应用发行。

## 共享插件与适配

按“共享插件 → Harness 适配 → 品牌/UI”维护。量子 Tools、Skills、MCP Server 与科学合同只维护一份；
Codex 展示目录直接来自共享声明，移除对 Desktop 设置服务的构建依赖。新增静态依赖检查，防止共享执行代码
反向导入 DSH 或 Electron；旧版品牌适配集中维护，保留原生界面交互。

## 日常使用

保留对话、工作区、文件、工具执行、审批、历史恢复，以及通用与模型设置。
默认界面没有登录、插件市场、Agent 预设管理、自动化中心、Magpie 专用连接页或学习通侧栏。
首次使用时添加自己的模型服务；需要科研计算时再准备相应环境。桌面恢复原生中英文，其他语言 README 和已有译文保留。

OpenQuantum 基于固定的 DSH Desktop `2.0.0` / Harness `0.1.0-rc.6`，保留正式扩展和生命周期机制。
捆绑的 Electron 为 `43.8.1`，包含基线恢复时审查过的依赖安全修复。上游许可证与署名随应用保留。

## 安装和升级

1. 下载 `OpenQuantum-0.8.5-macOS-arm64.dmg` 和 `SHA256SUMS`，核对摘要。
2. 退出旧桌面，备份 `~/Library/Application Support/OpenQuantum/` 以及自己选择的其他数据目录。
3. 打开 DMG，将 `OpenQuantum.app` 放入「应用程序」。旧品牌启动器应停用，或将其快捷入口指向新应用。
4. 打开 OpenQuantum，在独立目录中配置模型并开始新会话；退出后重开，再核对新会话与设置。

固定的 Harness 0.1.0-rc.6 使用 V0 会话格式；V1–V5 会话必须留在原 Home，不会自动降级或改写。
默认数据目录固定为 `~/Library/Application Support/OpenQuantum/Desktop/`，普通 Finder 和 Dock 启动也生效。
旧启动器的 `OpenQuantum/project/` 与 `OpenQuantum/native/` 保持原样；已有 V3 会话不能直接在此版本继续，
可另行导出阅读副本。模型与凭据可在备份后单独复制，不会随会话自动迁移。
旧的版本化凭据文件会先完整归档到 Home 下 `.openquantum-migrations/credentials-v1/`，再保留同名凭据引用与原值。
登录授权记录随原文件归档，简洁版不启用登录；无法明确对应的结构化 API Key 会拒绝转换。
遇到不兼容数据会停止准备；保留原目录并使用对应版本读取。程序替换不要求删除数据或旧 `versions/`。
完整路径、首次启动与回退边界见[安装说明](../DESKTOP_INSTALLERS.md)。

**签名状态：ad-hoc 本地签名，没有 Apple Developer ID 分发签名或公证。**
若 macOS 拦截，只在核对来源和摘要后按系统的单应用允许流程处理，不关闭全局安全检查。

## 验证与来源

发布前执行完整 `npm run check`、实际应用的首次部署与两次启动、捆绑 Node/uv、固定本地计算、
用户配置保留、首次 GUI 与既有数据副本升级检查。最终检查计数以 Release 中的验证附件为准；
跳过的外部 SDK 与硬件检查不计为通过，工程验证也不等于所有科研能力通过科学验收。

Release 附带 `release-validation.json`，记录最终源码提交、CI、安装包 SHA256、签名状态与实际验证范围。
最终附件从检查通过的干净提交构建，用户会话、配置、凭据与私有备份不进入安装包或验证附件。
