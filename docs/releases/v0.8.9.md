# OpenQuantum 0.8.9：凭据保护与可恢复升级

Desktop 与 Codex 插件使用统一产品版本 0.8.9，两个发行标签指向同一源码提交。共享插件、DSH/Codex 宿主职责和首页 / Skills / MCP 入口保持不变。

## 本次更新

- 共用设置页适配完整工作区，按 Skill 或 MCP 展开相关环境、账户与 Tool 使用限制；保存后读取核对，保留未确认的草稿。
- 旧 Harness Web 的 HTTP MCP 注册拒绝 URL 内嵌用户名、密码、查询参数和片段；已有地址的展示不回显这些内容。
- 外部服务调用按本次实际读取的凭据脱敏，覆盖调用期间轮换或新增凭据的情况。
- Web 与 Desktop 共用 Home 时采用一致的文件所有权记录。用户修改和有意删除保留，新默认放入待审阅目录；未修改的旧默认自动获得发行修复。
- Desktop 兼容迁移旧 persona 配置，并在替换程序前验证实际要保留的预设。存在冲突时保留原配置并停止升级。
- 程序、依赖链接、Home 准备与版本收据纳入同一次可恢复安装；普通失败回滚，中断后的下次安装或启动先恢复，再加载项目程序。

## 下载与升级

- [Desktop v0.8.9](https://github.com/xi-zhao/OpenQuantum/releases/tag/v0.8.9)：`OpenQuantum-0.8.9-macOS-arm64.dmg`，仅独立发布 macOS Apple Silicon。
- [Codex codex-v0.8.9](https://github.com/xi-zhao/OpenQuantum/releases/tag/codex-v0.8.9)：完整安装包、插件 ZIP 与 `SHA256SUMS`。

核对摘要后退出相关宿主并备份数据。Desktop 保留 `~/Library/Application Support/OpenQuantum/Desktop/`，Codex 保留插件身份、已有设置、凭据与计算环境；两个宿主不互相复制凭据。步骤见 [Desktop 安装](../DESKTOP_INSTALLERS.md) 和 [Codex 安装](../integrations/CODEX_AGENT_INSTALL.md)。

Desktop 仍固定 DSH Desktop 2.0.0 和原有 Harness family、V0 会话格式。应用采用 ad-hoc 本地签名，没有 Apple Developer ID 分发签名或公证。Intel Mac 与 Windows 的既有能力包渠道保持原样。

## 验证与边界

修复阶段定向回归 187 项：186 通过、0 失败、1 项真实 SDK 安装测试跳过。覆盖凭据轮换、共享 Home 往返、真实 v0.8.4 预设、安装失败回滚、进程中断与旧版重试。最终源码、PR/main CI、安装包摘要、签名、打包启动及本机升级结果以 Release 验证附件为准。

- 首次从旧应用内依赖布局升级时，外部已经替换掉的旧依赖无法恢复，因此仍须保留旧应用备份。
- 升级前退出使用同一 Home 的其他宿主；本次没有新增跨宿主活动锁。
- Windows 无法确认中断后的后代进程已经退出时，保留待恢复状态并停止；原生 Windows 中断尚未验收。
- 工程检查、运行完成和科学验收分别判断；本次不以打包或启动测试代替科学计算验收。
