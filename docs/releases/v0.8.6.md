# OpenQuantum 0.8.6：统一插件设置

简洁桌面的「设置」新增 **OpenQuantum** 入口，直接使用与 Codex 侧边应用相同的页面：

- 概览：Skill、Tool 与 MCP 的当前准备状态。
- Skill：按用途搜索与筛选，管理自动选择限制和关联环境。
- 凭据：按服务管理账户配置，已有密钥不回显。
- 高级设置：查看和管理 Tool、MCP 使用限制，以及自定义 MCP 连接。

两边共用页面、目录和受控设置逻辑，各宿主分别保存配置、凭据与使用限制。
打开设置只读取状态，不安装 SDK 或启动计算服务；准备状态也不代表远端调用成功。
桌面仍保留原生通用设置与模型表单，不增加登录或插件市场。

## 安装与兼容性

此发行提供 macOS Apple Silicon 的 `OpenQuantum-0.8.6-macOS-arm64.dmg`。
退出旧桌面并备份数据后，将镜像中的应用替换到「应用程序」。
从 0.8.5 更新继续使用 `~/Library/Application Support/OpenQuantum/Desktop/`，保留既有会话、模型和设置。
更早的 V1–V5 会话仍留在原数据目录，不会转换为旧格式。

桌面基线仍为 DSH Desktop **2.0.0** / Harness **0.1.0-rc.6**。
Codex 公开安装版本仍为 `codex-v0.8.4`，本次不单独发布 Codex 插件。
完整安装方式见[安装说明](../DESKTOP_INSTALLERS.md)。

**应用采用 ad-hoc 本地签名，没有 Apple Developer ID 分发签名或公证。**
下载后可用附带的 `SHA256SUMS` 核对完整性；不需要关闭系统安全检查。

最终源码、CI、镜像摘要以及设置页面和升级保留的实际验收范围记录在 Release 的验证附件中。
