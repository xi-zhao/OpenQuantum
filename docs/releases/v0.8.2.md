# OpenQuantum 0.8.2 — 原版 DSH Desktop 能力包

OpenQuantum Desktop 能力包与 [Codex 插件 0.8.2](https://github.com/xi-zhao/OpenQuantum/releases/tag/codex-v0.8.2) 使用同一产品版本，发布源码为 `64004f9fcef58afa2a8a05d965eebcaa6c9477ab`。

## 本版调整

- 使用 [anywhere-labs 原版 DSH Desktop 2.0.7](https://github.com/anywhere-labs/dsh-desktop/releases/tag/v2.0.7)，保留原版布局和设置方式。OpenQuantum 保留品牌、量子组件、量子学习通和更新入口。
- 隐藏内测声明，移除未配置的示例 Gateway 与默认模型。模型由用户在原生设置中添加；已有用户配置继续保留。
- 简化量子模式简介，量子组件采用 Tools、MCP、Skills 名称，技术诊断默认折叠。
- 修复 Desktop Profile 依赖隔离与配置冲突提示，安装和再次安装保留已有用户配置。
- 共享量子能力包含已合入主线的 Pasqal 实验工作流；完整原生 SDK 路径与便捷 Tool 并存。

## 选择下载

| 系统 | OpenQuantum 能力包 |
| --- | --- |
| Mac Apple Silicon | `OpenQuantum-0.8.2-DSH-darwin-arm64.tar.gz` |
| Mac Intel | `OpenQuantum-0.8.2-DSH-darwin-x64.tar.gz` |
| Windows x64 | `OpenQuantum-0.8.2-DSH-win32-x64.tar.gz` |

先安装原版 DSH Desktop **2.0.7**，再下载本页对应能力包，按 `SHA256SUMS` 核对摘要并解压。退出正在运行的 OpenQuantum Host，在 Mac 运行 `install.command`，在 Windows 运行 `install.cmd`，随后通过安装器输出的 OpenQuantum 启动入口打开。升级前备份已有 OpenQuantum 数据目录；不要删除 `versions/`。

本页能力包包含 Node、uv 和锁定的程序依赖，不包含改版的 DSH DMG/EXE。第三方客户端保留上游名称、版本和更新渠道；OpenQuantum 产品版本为 **0.8.2**。Harness 保持 **0.1.5-rc.1**，不升级，不支持用此版本改写 Harness 0.2 的 V4 Home。设置过原生数据目录的用户，须在 DSH Desktop 中选择本次安装的 `project/.openquantum/dsh`。

详细安装、配置保留与迁移说明见[桌面安装文档](https://github.com/xi-zhao/OpenQuantum/blob/main/docs/DESKTOP_INSTALLERS.md)。模型凭据与量子 SDK 依赖仍由用户按需配置。
