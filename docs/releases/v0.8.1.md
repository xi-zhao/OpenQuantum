# OpenQuantum 0.8.1

Desktop、Codex 插件和安装器从本版起统一使用 **0.8.1**。以后同步更新只需记录一个 OpenQuantum 产品版本号；`v0.8.1` 与 `codex-v0.8.1` 是同一源码提交的两个发行渠道。此前 Desktop 0.7.0 和 Codex 0.8.0 的已发布记录保留。

本次统一版本管理，不改变 SDK 能力、固定依赖或科学合同。继续提供 85 个 SDK/源码环境的原生公开 API 路径，允许编写自定义程序、组合算法和保存完整工件；便捷 Tool 的预设案例不限定库的使用范围。Codex 包含 133 个 Skill、71 个科学 Tool。逐库范围见[完整 SDK 接入记录](../integrations/FULL_SDK_ACCESS.md)；85 项是环境入口，不代表 85 个不同上游库，也不表示全部 API 或平台均已验证。

## 下载与升级

[Desktop Release](https://github.com/xi-zhao/OpenQuantum/releases/tag/v0.8.1) 提供以下文件，以及 `SHA256SUMS` 和逐包验证记录：

- `OpenQuantum-0.8.1-macOS-arm64.dmg`：Apple Silicon Mac。
- `OpenQuantum-0.8.1-macOS-x64.dmg`：Intel Mac。
- `OpenQuantum-0.8.1-Windows-x64-Setup.exe`：Windows x64。

Desktop 安装包仍为**未签名测试构建**，没有 Apple 签名/公证或 Windows 代码签名。按[数据与升级](../DESKTOP_INSTALLERS.md#数据与升级)保留用户目录、会话、模型及自定义 Skill/MCP 配置，然后替换应用。稳定更新清单与 GitHub `latest` 继续属于 Desktop。

[Codex Release](https://github.com/xi-zhao/OpenQuantum/releases/tag/codex-v0.8.1) 提供 `openquantum-0.8.1-codex-install.zip` 完整安装包、`openquantum-0.8.1-codex-plugin.zip`、`SHA256SUMS` 和逐包验证记录。需要 Node.js 24+、npm 及支持插件的 Codex；核对摘要后，在完整安装包的解压目录执行：

```sh
npm ci --ignore-scripts
npm run plugin:install
```

也可按[Agent 安装指南](../integrations/CODEX_AGENT_INSTALL.md)让 Codex 安装。安装器保留 `openquantum@personal` 身份、其他插件和用户配置，随后按宿主提示重载。

两个渠道都不会批量安装 SDK 环境。按实际任务显式准备依赖；账户、鉴权、许可、私有依赖和特殊硬件限制仍适用。Harness `0.1.5-rc.1`、Desktop 依赖 `2.0.7` 与内置 Node.js `24.14.1` 保持原有独立依赖版本，它们不等于 OpenQuantum 产品版本。

## 后续版本管理

根 `package.json` 是产品版本的唯一来源。维护者使用以下命令同时更新 Desktop、Codex 插件、安装器及三份锁文件：

```sh
npm run release:version -- X.Y.Z
npm run release:check
```

该命令保留依赖版本，并在写入前拒绝无效版本、降级和不完整的版本字段。CI 与两个打包入口检查一致性，防止只更新某一个渠道。同步发行使用同一提交的 `vX.Y.Z` 与 `codex-vX.Y.Z` 标签；用户更新记录可只写“OpenQuantum X.Y.Z”。流程见[发布与更新](../UPDATES.md#publishing-a-stable-update)。

## 验证范围

发布要求当前提交的 CI、Mac arm64/x64 与 Windows x64 安装验证、Codex 干净提交打包、隔离安装、原生宿主检查、附件摘要及 Desktop 更新清单核对。实际结果、源码提交和附件哈希以两个 Release 的 `release-validation.json` 及关联工作流为准。Desktop 的安装检查不等于各平台的全部 SDK 验证；Codex 原生宿主检查限定为本机 macOS arm64。

此前 13+30+24+18 项 SDK 工程记录沿用各自的平台和执行范围，本版没有重新开展真实科研任务验收。**`scientificValidation=not_evaluated`**；安装成功、Tool 完成和 Validator observations 不等于最终科学 Acceptance。未进行真实云提交、QPU、实验室设备或外部模型验收。

## English

OpenQuantum 0.8.1 unifies the product version across Desktop, the Codex plugin and its installer. Both release tags point to the same commit; their prefixes identify distribution channels. One command updates all product manifests and lockfiles, and CI and packaging reject version drift. Existing SDK capabilities and dependency versions remain unchanged. Desktop installers remain unsigned test builds, SDK setup is explicit, and engineering validation does not establish scientific acceptance.
