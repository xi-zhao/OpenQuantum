# OpenQuantum 0.8.10：扩大设置工作区并修复滚动

0.8.9 的设置页在普通 Desktop 窗口中给目录和详情留下的高度过小；鼠标位于固定筛选区时不能滚动列表，展开账户表单还可能产生无内容的页面溢出。本次补丁同时用于 Desktop 与 Codex 的共享设置页。

## 本次更新

- 品牌与首页 / Skills / MCP 导航合并为一行，目录页收拢重复标题和说明；生效范围仍可见。
- Desktop 的许可证链接移入设置导航，缩小共享页尾，把主要空间交给目录与详情。
- 搜索、筛选和条目在同一个目录区域内滚动；目录和详情都支持键盘翻页，选择条目及窄窗口返回时保留目录位置。
- 短窗口按宿主实际高度布局，目录与详情底部留在窗口内；隐藏的表单标签约束在详情区内，避免滚到底出现大段空白。
- 打包验收实际发送 Chromium 滚轮和键盘输入，并检查内容区高度、详情底部、完整页尾及目录位置保留。

## 下载与兼容性

- [Desktop v0.8.10](https://github.com/xi-zhao/OpenQuantum/releases/tag/v0.8.10)：`OpenQuantum-0.8.10-macOS-arm64.dmg` 与 `SHA256SUMS`。
- [Codex codex-v0.8.10](https://github.com/xi-zhao/OpenQuantum/releases/tag/codex-v0.8.10)：完整安装包、插件 ZIP 与 `SHA256SUMS`。

两端使用同一产品版本和源码提交。共享插件、宿主职责、模型路由、科学合同、按需环境准备和凭据隔离保持原样。Desktop 继续固定 DSH Desktop 2.0.0、原有 Harness family 和 V0 会话格式。

按 [Desktop 安装说明](../DESKTOP_INSTALLERS.md) 或 [Codex 安装说明](../integrations/CODEX_AGENT_INSTALL.md) 升级并保留原数据。Mac 应用采用 ad-hoc 本地签名，没有 Apple Developer ID 分发签名或公证。既有 Intel Mac 与 Windows 能力包渠道不变。
