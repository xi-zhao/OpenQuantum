# OpenQuantum 0.8.7：简洁原生菜单

菜单栏统一使用 OpenQuantum 图标，只保留 **打开 OpenQuantum** 与 **退出 OpenQuantum**，
跟随设置中的中文或英文。窗口固定为 compatibility 样式，不再提供 DSH Terminal 或 Advanced Mode 入口。
Agent 的终端执行 Tool 继续遵循所选权限；「设置 → OpenQuantum」保留首页、Skills、MCP。
macOS 系统应用菜单中的 About、Hide、Quit 也统一使用 OpenQuantum 名称。

## 实现边界

共享 Skills、Tool implementation、MCP Server 与科学合同未改。
品牌 Host Plugin 经公开的 Desktop 调度接口提供名称、窗口与菜单栏图标、语言和菜单规则。
固定 Desktop 2.0.0 没有原生菜单精简选项，因此源码构建应用一份受控的最小展示接口补丁；
原生壳继续负责打开、退出和资源回收。补丁及实际菜单模块的摘要进入构建验证，编译后恢复上游源码。
没有修改 `node_modules`、引入新生产依赖或建立第二套 Agent Runtime。

## 安装与兼容性

本次只发布 macOS Apple Silicon 的 `OpenQuantum-0.8.7-macOS-arm64.dmg` 与 `SHA256SUMS`。
核对摘要、退出旧版并备份数据后，将镜像内的应用替换到「应用程序」。
继续使用 `~/Library/Application Support/OpenQuantum/Desktop/`，保留已有会话、模型与设置。
更早的 V3 会话及阅读副本保持独立，不转换为旧格式。

基线仍为 DSH Desktop **2.0.0** / Harness **0.1.0-rc.6**；Codex 公开插件仍为 `codex-v0.8.4`。
**应用为 ad-hoc 本地签名，尚未取得 Apple Developer ID 分发签名或公证。**
完整安装方式见[安装说明](../DESKTOP_INSTALLERS.md)。
