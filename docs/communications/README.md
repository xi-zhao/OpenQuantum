# 宣传与媒体素材边界说明

本目录存放公众号、宣传片与小红书图文等非运行时素材（配套渲染脚本见 [`scripts/render-openquantum-xhs.py`](../../scripts/render-openquantum-xhs.py)）。

- **与产品运行解耦**：本目录与 `scripts/render-openquantum-xhs.py` 不被任何运行时代码、桌面打包、Codex 插件或自动化测试引用。
- **治理状态（2026-11-24）**：按治理计划，本目录属于待迁出/外部归档的宣传资产（含多张 1 MB+ 原始截图与导出图）。完成外部素材仓库或 Release 归档后再从主工程仓移除。
- **增量约束**：迁出前请勿继续向本目录提交新的 MB 级原始 PNG / 视频导出产物。
