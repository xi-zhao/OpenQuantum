为什么“未推导验收”反而是亮点？

为什么值得研究者长期信赖

开放插件架构，
与清晰的科学边界

OpenQuantum 不再造封闭的 Agent Runtime，不锁定任何单一模型厂商，也不把“程序没有报错”混同为“科研结论成立”。

一份共享插件，多宿主运行

同一套 Skill、Tool 与科学契约同时驱动 Codex 插件与 OpenQuantum Desktop / Web，接入任意支持 Tool Calling 的模型服务，把研究工作流沉淀在开放标准里。

按需准备与凭据隔离

能力发现默认只读，执行期绝不隐式安装；量子云凭据按宿主隔离管理（Codex 存入本机系统凭据库，Desktop 由 Harness 凭据提供方或启动环境读取），不写入配置、源码或对话记录，真实硬件任务必须显式授权。

执行完成 ≠ 科学验收

独立 Validator 产出结构化科学观测，宿主全沙箱运行独立参照程序，仅由 central Acceptance Builder 结合完整来源链推导验收结论。当前源码主线已为 DSH Desktop / Web 接通 11 项可回放 L3 能力，Codex 复用计算与观测。
