# 一维热方程薛定谔化原型

这是判断量子 PDE 计算接入成本的独立实验，采用现有 NumPy/SciPy，自行实现公开数学构造。
它没有安装或调用 UnitaryLab 模拟器，没有新增产品 Skill、Tool 或科学验收门槛。

## 问题与方法

固定无量纲方程 `u_t = a u_xx`，区间 `[0,L]`，两端零 Dirichlet 边界，无源项。
初态为 `sin(πx/L) + 0.25 sin(3πx/L)`；空间只允许 4、8、16 个内部网格点。

中心差分给出负定实对称矩阵 `A`。采用 `v(0,p)=exp(-|p|)u(0)`，在辅助变量 p 上作正交归一 FFT，
逐频率求解 `v_hat'(μ)=-i μ A v_hat(μ)`，即幺正演化 `exp(-i μ A T)`。
逆 FFT 后在 `p=1` 恢复 `u(T)=exp(p) v(T,p)`；实现显式恢复了编码时的初态范数。
方法依据 [Jin、Liu、Yu，arXiv:2407.15895v3，第 2 节](https://arxiv.org/html/2407.15895v3#S2)，代码独立编写，未复制论文图文或闭源实现。

对同一有限维扩展状态提供两种求解：

- `spectral`：空间本征分解与辅助 FFT 的精确有限维幺正演化。
- `strang`：把相邻耦合拆为偶边/奇边，进行二阶 Strang 乘积；对角部分可交换，单独精确作用。

辅助网格固定为 128、256、512、1024 点之一，区间默认 `[-8,8)`。恢复位置必须落在网格上；
用离散算子的最大传播速度检查恢复点的特征线不会越过辅助区间。未支持的 `block` 等方法直接失败。

## 验证与复现

```bash
# 当前实验使用 Python 3.13.2；依赖的固定版本见 requirements.txt。
# 如已有匹配环境，无需安装。
python3 -m unittest discover -s experiments/schrodingerization-heat1d -p 'test_*.py' -v
python3 experiments/schrodingerization-heat1d/run.py --output .openquantum/validation/schrodingerization-heat1d
```

需要新环境时，可在自己的隔离 Python 环境中安装本目录 requirements.txt；脚本自身不安装任何依赖。
数值测试覆盖零时刻复振幅恢复、离散正弦模解析解、幺正范数、辅助网格与时间分裂收敛、无效范围和无隐式回退。
数据保留复数解的虚部，不以只取实部掩盖有限辅助网格误差。

[2026-09-12 实验报告](evidence/2026-09-12/report.md)与[完整数据](evidence/2026-09-12/results.json)
分别记录空间离散、辅助网格、时间分裂误差。测试中的数值回归断言只约束此原型，不是产品 Acceptance Profile。

## 边界与接入判断

默认 8×512 的扩展态包含 4096 个复振幅，对应 12 个逻辑寄存器量子位、单个 complex128 态矢 64 KiB。
这些数字没有计入额外工作数组、状态制备、门综合、误差纠正及读出。当前通过经典内存访问完整振幅恢复解，
实际 QPU 上的状态制备、测量概率和精度开销仍需单独评估。

原型表明无需依赖闭源模拟器即可研究这条数学路线。产品化还需要开源电路实现、资源与读出分析、输入/输出合同及独立科学审阅。
本轮没有门级电路验收、真机执行、二维或非齐次边界支持，也没有量子加速或最终科学验收结论。
